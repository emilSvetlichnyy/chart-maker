How to choose

Use pie or donut for parts of one whole, bar or H. Bar to compare categories, line or area for change over time, scatter for X/Y relationships, radar for multi-axis profiles, stacked for composition inside categories, and gantt for task dates.

Which chart types should you learn first?

Start with pie chart (parts of a whole), bar chart (compare categories), and line chart (trends). Then add area, scatter, radar, and gantt as your data visualization questions get more specific.

VIA’s chart maker app includes ten chart types. Browser chart maker tools on this site cover pie and bar only. Use the chart type decision guide before you open any tool.

Questions

How many chart types does VIA support?

Ten: Pie, Donut, Line, Area, Bar, H. Bar, Stacked, Scatter, Radar, and Gantt.

Which types work in the browser?

This website’s live tools are pie and bar only.

Which types need Pro to export?

Stacked, Scatter, Radar, and Gantt.

Is spider chart a VIA type?

The app label is Radar. Spider chart is a common synonym in education, not a separate VIA UI label.
