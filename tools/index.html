What is not online

There is no browser import from Excel or Google Sheets, and no automatic handoff into VIA. If you start online, re-enter values in the app when you need other chart types or saved projects.

Questions

Which chart makers work online here?

Pie and bar only.

Can I import Excel into the online tools?

No. Type label and value fields manually.

Can the online chart open inside VIA automatically?

No. There is no browser-to-app data handoff. Re-enter values in VIA if you continue on iPhone.

Where are line, radar, and gantt?

In the VIA iOS app. See the chart types hub.
