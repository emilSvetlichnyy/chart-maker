What is a radar chart?

A radar chart plots each variable on an axis radiating from the center. Connecting the points creates a polygon — strong areas push outward, weak areas stay near the middle.

Common uses: skill assessments, product feature scores, survey dimensions, sports ratings. Keep 5–8 axes; more than that is hard to read.

When a radar chart works

You are comparing profiles across the same set of dimensions.
Values share a similar scale (for example 1–10), so axes stay fair.
You need a phone-native editor — open VIA instead of fighting Numbers menus.

Questions

What is another name for a radar chart?

Spider chart, web chart, or star plot — same idea: scores on radial axes.

Can I make a radar chart on iPhone?

Yes. VIA includes radar charts as a native iOS chart type.

Radar chart or bar chart?

Radar for multi-dimension profiles. Bar when you only need “which is bigger?”

Is VIA free?

The app is free to start. Some features may require an in-app purchase.

Do I need Excel for a spider chart?

No. Enter scores directly in VIA on iPhone.
