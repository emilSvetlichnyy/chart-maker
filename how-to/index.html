How to make a chart (start here)

Pick the chart type for your question, enter values in a chart maker or graph maker, then export a PNG. Use choose a chart type if you are unsure whether you need a pie chart, bar chart, or line chart.

Questions

Can I paste an Excel table into these guides?

No automated paste/import exists. Copy values by hand into the pie/bar fields or into VIA.

Do guides require the app?

No. Educational steps stand alone. App CTAs appear only where VIA supports the chart type.

Where do I start for a quick PNG?

Use the free pie or bar makers under Tools.
