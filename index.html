Which chart should you use?

Line / AreaTrend
ScatterX·Y
RadarProfile

Pie / Donut — parts of one total.

Bar / H. Bar / Stacked — compare categories (stacked adds parts inside each bar).

Line / Area — change over time.

Scatter — relationships between two numbers.

Radar — multi-axis profiles (also called spider charts in education).

Gantt — tasks with start and end dates.

Questions

What is VIA?

VIA is a native iOS chart maker with ten chart types (pie, donut, line, area, bar, H. Bar, stacked, scatter, radar, gantt). Enter data, preview, then export or save locally on iPhone.

Can I use this without installing the app?

Yes. The free pie and bar makers on this site work in the browser with no signup. There is no automatic handoff into VIA — re-enter values in the app for other types or saved projects.

Is it free?

The online tools are free. The App Store app is free to start; some features may require an in-app purchase.

Do I need Excel?

No. Type values here, or copy two columns from a spreadsheet. See the From table page if your data is already in Excel or Sheets.

What chart types does VIA support?

Ten types in the native iOS app: pie, donut, line, area, bar, H. Bar, stacked, scatter, radar, and gantt. This website’s live makers are pie and bar only.

Chart maker or graph maker — is there a difference?

Here they mean the same thing. Use the graph maker hub if you searched for “graph maker.”
