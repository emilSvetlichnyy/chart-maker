Questions

Direct answers before the install CTA.

What is VIA?

VIA is a chart & graph builder for iPhone. Enter data, pick pie, bar, or line, then customize and export without a heavy spreadsheet UI.

Can I use VIA without installing the app?

Yes. These website pages answer chart questions and include free browser makers for pie and bar. The app adds saved charts, more types, and phone-native editing.

Is this free?

The online tools on this site are free. VIA on the App Store is free to start, with optional in-app purchases for expanded use.

Do I need Excel?

No. Type numbers here, or copy values from a table. If your data is already in Excel or Sheets, start on the From table page.
