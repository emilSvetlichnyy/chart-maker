When to use a pie chart

Use it when categories add up to one total: budget, survey answers, traffic sources.
Keep 3–6 slices. Group the rest as “Other”.
To compare sizes across months or regions, use a bar chart instead.

How to make a pie chart

1. Add labels and values

Raw numbers are fine. The tool converts them into percentages.

2. Check the preview

If many slices look tiny, merge them or switch to a bar chart.

3. Download or open VIA

Save a PNG here. For colors, other chart types, or saved projects, re-enter values in VIA on iPhone.

Questions

Is this pie chart maker free?

Yes. You can build and download a PNG on this page at no cost.

Do I need Excel?

No. Type values into the fields on this page.

Can I make a pie chart on iPhone?

Yes — use this page in Safari, or install VIA for a phone-native editor.

How many slices should I use?

Usually 3–6. More than that is hard to read.

Pie chart vs donut chart?

Same idea. A donut leaves the center open for a total. See the donut chart guide, or use VIA for both styles in the native iOS app.

What other chart types does VIA support?

VIA includes ten types: pie, donut, line, area, bar, H. Bar, stacked, scatter, radar, and gantt. This page’s live tool is pie only.
