Before you start

What can change whether a pie chart is the right choice.

Pie charts work when categories add up to one whole — budget, survey mix, traffic sources.
Too many tiny slices make the chart hard to read; group the rest as “Other”.
If you need to compare sizes across time or places, a bar chart is usually clearer.

What a pie chart is good for

A pie chart (or donut) maps each category to a slice of 100%. Readers should see the big shares first — not decode ten near-identical wedges. VIA keeps the flow simple: enter numbers, preview, export, or open the app.

Use percentages or raw values

Either works. The maker converts values into shares so you can paste from a table without pre-calculating.

Label the meaningful slices

Name what matters. Vague labels (“Misc”, “Stuff”) weaken the chart even if the math is perfect.

Export when you’re done

Download a PNG for slides and chats, or jump into VIA to keep editing on iPhone.

Switch types if needed

If comparison matters more than composition, move to the bar maker — same data habit, clearer story.

Questions

Is this pie chart maker free?

Yes. Build and download from this page at no cost. VIA on the App Store is free to start with optional upgrades.

Do I need Excel to make a pie chart?

No. Type labels and values here. If your data is already in a spreadsheet, copy the two columns or use the From table guide.

Can I make a pie chart on iPhone?

Yes — use this page in Safari, or install VIA for a phone-native editor with more chart types.

How many slices should a pie chart have?

Usually 3–6. Beyond that, merge smaller categories into “Other” or switch to a bar chart.

Pie chart vs donut chart?

Same job: parts of a whole. A donut leaves the center open for a total or title — VIA can handle both styles in-app.
