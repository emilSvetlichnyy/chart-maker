Stacked bar chart — Stacked in VIA.

A stacked bar chart shows how segments add up within each category. In VIA the type is labeled Stacked. You can build and preview it for free; exporting Stacked requires VIA Pro.

What is a stacked bar chart?

A stacked bar chart places segments on top of each other in each bar so you can read both the total and the composition of each category.

When should you use it?

Each category has parts that should add to a total.
You need composition and comparison in one view.
For a single share of one whole, pie or donut is simpler.

How to make it in VIA

1. Open VIA

Create or open a chart project.

2. Choose Stacked

Select Stacked from the chart type list.

3. Enter segments

Add titled points and values that make up each stack.

4. Export with Pro

Export of Stacked charts requires VIA Pro.

Limits in VIA

Exporting Stacked charts requires VIA Pro. Free users can still select and edit Stacked charts in the app.

Questions

Does VIA support stacked bar charts?

Yes. The UI label is Stacked.

Is stacked bar export free?

No. Stacked is a Pro-gated export type. You can still select and edit it on the free tier.

Stacked or regular bar?

Use stacked when each bar has internal parts. Use regular bar for one value per category.

Is there an online stacked bar maker?

No. Use the VIA iOS app.

Do I need Excel?

No. Enter values in VIA.
