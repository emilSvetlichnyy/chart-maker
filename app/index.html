VIA — native chart maker for iPhone.

VIA (Chart Builder) is a native iOS and iPadOS app. It is not a web wrapper. Use it when you need chart types beyond the free browser pie and bar tools, saved projects, or device export.

Verified facts

Ten chart types. Local project storage. Export PNG, JPEG, PDF. Free tier: one saved project and three custom colors. Pro is required to export Stacked, Scatter, Radar, and Gantt. No Excel/CSV import and no browser-to-app handoff.

Questions

Is VIA free?

Free to download and start. Some limits and Pro-gated exports apply.

Does VIA import Excel?

No. Enter values in the app.

Can a browser chart continue automatically in VIA?

No automatic handoff. Re-enter values in the app.
