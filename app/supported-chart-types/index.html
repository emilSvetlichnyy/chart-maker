Source of truth

Defined in ChartBuilder Models/ChartModels.swift as enum ChartType. Legacy strings Lollipop, Step, Waterfall, Range, and Transform migrate to Bar and are not selectable types.

Which chart types does VIA support?

VIA supports ten chart types for mobile data visualization. Browser chart maker tools cover pie and bar only; the rest are built in the iPhone app.

Questions

How many types?

Ten selectable types.

Which need Pro to export?

Stacked, Scatter, Radar, Gantt.

Is Donut supported?

Yes, as a separate Donut type in the app.
