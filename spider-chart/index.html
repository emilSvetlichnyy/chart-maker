Synonym · Radar

Spider chart — same idea as radar.

Spider chart, web chart, and star plot usually mean a radar chart: scores on axes around a center. VIA implements this as Radar (not a separate Spider label). Exporting Radar requires VIA Pro.

What is a spider chart?

A spider chart plots several variables on axes that radiate from a center and connects the scores into a polygon. In most tools — including educational materials — spider chart and radar chart refer to the same visual.

When should you use it?

You are comparing a profile across the same dimensions.
Values share a similar scale.
In VIA, choose the Radar type.

How to make it in VIA

2. Choose Radar

Select Radar — there is no separate Spider control.
