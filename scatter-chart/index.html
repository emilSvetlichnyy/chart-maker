What is a scatter chart?

A scatter chart places each observation at coordinates (X, Y). Patterns in the cloud of points can suggest correlation, clusters, or outliers.

When should you use it?

You have two numeric measures per item.
You want relationships, not category rankings.
For ordered time series, prefer line or area.

How to make it in VIA

1. Open VIA

Create a project in the native iOS app.

2. Choose Scatter

Select Scatter. Each point has X and Y fields.

3. Enter pairs

Add titles plus X and Y values.

4. Export with Pro

Export of Scatter charts requires VIA Pro.

Limits in VIA

Exporting Scatter charts requires VIA Pro. Free users can still select and edit Scatter charts.

Questions

Does VIA support scatter charts?

Yes. Scatter uses X and Y numeric fields.

Is scatter export free?

No. Scatter export requires VIA Pro. Editing remains available on the free tier.

Scatter or line chart?

Scatter for unordered X/Y pairs. Line for ordered series over time.

Is there an online scatter maker here?

No. Use VIA on iPhone.

Do I need Excel?

No. Enter X and Y in VIA.
