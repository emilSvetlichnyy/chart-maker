What is a line chart?

A line chart plots values against an ordered axis — usually dates, weeks, or months — so you can see rise, fall, and seasonality at a glance.

Use it for weight logs, sales by week, temperature, study hours, or any series where order matters. For category totals with no time order, prefer a bar chart.

When to use a line chart

You have 4+ points in a clear sequence (days, weeks, months).
The question is “how did this change?” not “which slice is biggest?”
You want to keep the chart on your iPhone and update values later in VIA.
