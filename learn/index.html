FAQ

Is this marketing for VIA?

Guides are written to stand alone. VIA is mentioned only where it implements the chart type or workflow.

Where should I start?

Start with Choose a chart type, then open the matching comparison or type guide.

Do you cover Excel or Tableau?

We teach chart choice and literacy. Product-specific Excel/Tableau menus are out of scope; we stay honest about what VIA does and does not do.

Build it on iPhone

When you want a native editor with ten chart types and PNG/JPEG/PDF export, open VIA. Re-enter values in the app — there is no automatic browser handoff.
