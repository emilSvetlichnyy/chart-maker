Common chart mistakes.

These errors show up in homework, decks, and dashboards. Fix the question first, then the visual.

Quick answer

Most chart failures are mismatched intent: pie for ranking, line for unordered categories, radar for exact comparison, or bars with a truncated baseline that exaggerates gaps.

FAQ

What’s the most common pie mistake?

Too many slices. Cap at roughly 3–6 and group the rest as Other.

Is a truncated axis always wrong?

It can exaggerate differences. If you truncate, say so — readers assume a zero baseline on bars.

Spider vs radar?

Same idea educationally. VIA’s UI label is Radar, not Spider.
