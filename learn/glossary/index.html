Glossary

Chart vocabulary, defined.

Short definitions you can cite. Product limits are stated when a term maps to VIA behavior.

Chart

A visual representation of data using position, length, angle, area, or color.

Graph

In everyday use, often synonymous with chart. In mathematics, a graph can also mean nodes and edges—different from a data chart.

Legend

A key mapping colors or symbols to categories.

Axis

A scaled reference line for plotted values.

Series

A set of related values. VIA supports one flat series of points.

Data point

One observation: typically a label plus numeric value (and X or dates for some types).

Part-to-whole

A relationship where categories sum to a single total—classic pie/donut job.

Correlation

A relationship between two variables visible on a scatter plot; not proof of causation.

Export

Saving a chart image or PDF for sharing. VIA supports PNG, JPEG, and PDF.

Baseline

The zero (or reference) line bars are measured from. Truncating it can exaggerate differences.

FAQ

Chart or graph?

In everyday data viz, the words are often interchangeable. See the chart vs graph guide.

Does VIA support multiple series?

No. VIA uses a single flat series of points. Documented as a product limit.

Where are chart type definitions?

Each type page and the chart types hub.
