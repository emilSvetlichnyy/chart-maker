What is a gantt chart?

A Gantt chart lists tasks as horizontal bars spanning from a start date to an end date so schedules and overlaps are visible.

When should you use it?

You are planning tasks with start and end dates.
You need a phone-native timeline, not a full project suite.
For simple category totals, use a bar chart instead.

How to make it in VIA

1. Open VIA

Create a project in the native iOS app.

2. Choose Gantt

Select Gantt. Fields are Task, Start, and End.

3. Set dates

Use the date pickers. Start has a Today shortcut.

4. Export with Pro

Export of Gantt charts requires VIA Pro.

Limits in VIA

Exporting Gantt charts requires VIA Pro. Free users can still select and edit Gantt charts. Gantt has no Legend toggle in the editor.
