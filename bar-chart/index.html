What is a bar chart?

A bar chart compares values across categories — months, regions, products, or scores — using bar length so you can see which item is larger at a glance.

When should you use a bar chart?

Use bars when the question is “which is bigger?”
Keep units the same on one chart (don’t mix % and dollars).
For parts of one whole, a pie chart is usually clearer.
